This Arduino circuit contains Arduino Uno, 4×4 keypad and 7-segment display which work together to receive and display the user input. The keypad is an input device which is used to input the numbers and characters by pressing the keys. The Arduino is always checking the keypad to see which button is pressed. Once the key is recognized the Arduino processes the input and sends the appropriate signals to the 7segment display. Then the display turns on the respective segments to show the number that the user has entered. A simple system that demonstrates the ability of an Arduino to read from an input device and provide visual feedback via an output device based on the input device.
